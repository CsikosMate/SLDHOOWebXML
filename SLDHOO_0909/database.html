Adatbázis rendszerek Web technológiák 1 Webes adatkezelő környezetek

Adatbázis rendszerek

Kredit: 5

Ajánlott félév: 3

Tematika:

  1. Adatkezelés alapfogalmai, adatperzisztencia szintje, a file kezelés struktúrája és funkciói. C alapú filekezelés, Java alapú filekezelés
  2. RDBMS alapfogalmai; DB fejlesztés lépései, SDM modellek áttekintése, ER adatmodell, az ER alapú modellezés lépései
  3. ER adatmodellezés módszertana, az EER és UML adatmodellek. Relációs adatmodell, relációs struktúra és integritási feltételek. ER modell konverziója.
  4. SQL nyelv áttekintése, SQL DDL nyelvi elemek.
  5. Szerver architektúra,SQLite és az Oracle APEX és Oracle SQLDeveloper felület.
  6. Relációs adatmodell műveleti része, relációs algebra. SQL DML és DQL alapok.
  7. SQL SELECT utasítás további elemei, kapcsolódás a relációs algebrához, al-SELECT és összetett lekérdezések.
  8. SQL speciáis elemei: dátum kezelés, sztring kezelés. Tranzakció elemei, VIEW mechanizmus. Fizikai szintű tárolási módszerek, indexelés
  9. Az adatmodellezés problémái, a függőségek szerepe. Függőségek szabályai, Normálformák.
  10. Dekompozíciós szabályok. Adatbázisok de-normalizálása, N1NF adatbázisok.
  11. Az SQLite DBMS architektúra elemei, SQL-API rendszerek, SQL_API típusai; SQLite API C nyelvből, C programok fejlesztése
  12. A JDBC keretrendszer architektúrája, JDBC - Java osztályok, alap funkciókat megvalósító Java JDBC programok fejlesztése.
  13. Adatbázisok védelmi modelljei, A DAC védelmi modell, szerepkörök alkalmazása; a MAC védelmi modell elemei.
  14. Kitekintés a NoSQL modelleke. Felhő alapú adatbázisok.
